# STM32-Blue-Pill-Line-Following-Robot-Board
STM32 Blue Pill tabanlı, 3S LiPo uyumlu çizgi izleyen robot PCB'si. Donanımda 1N5822 ters kutup koruması, LM7805 filtreli regülatör devresi, TB6612FNG motor sürücü bağlantıları ve mod seçimi için PB10-PB11 pinlerine bağlı 2'li DIP switch yer alır. Güç hatları yüksek akım için 1.5mm kalınlığındadır.
